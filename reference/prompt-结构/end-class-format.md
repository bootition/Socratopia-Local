# 课后更新格式

从 Socratopia v2.1.1 的 [chat/route.js](/D:/Users/qhdjxgm/AppData/Local/Programs/Socratopia/resources/server/.next/server/app/api/chat/route.js)（模块 7788）中提取。

**触发方式**: 学习者发送 `[下课]` / `[下課]` / `[End Class]` 指令。

---

## 7 段分隔符格式

AI 必须以以下分隔符输出 7 段内容，每段以 `===TAG===` 开头：

```
===FAREWELL===
（告别语，显示给学习者）

===PAL_MOMENTS_MD===
（单个新条目：## YYYY-MM-DD | 伙伴名 + 内容段）

===PROGRESS_MD===
（教材学习进度记录）

===DIARY_ENTRY===
（日记条目，使用真实日期）

===RELATION_MD===
（关系状态更新，可留空）

===COMPANION_NOTE===
（伙伴内心独白，≤ 80 字符）

===END===
```

---

## 各段详细规范

### ===FAREWELL===
- **内容**: 对学习者说的告别语
- **显示**: 直接展示给学习者
- **语言**: 遵守授课语言要求
- **特殊**: 如果对话很短或没实质内容，只写一句简短自然的告别

### ===PAL_MOMENTS_MD===
- **格式**: `## YYYY-MM-DD | 伙伴名` + 换行 + 内容段
- **视角**: 第三人称
- **目的**: 教学互动备忘——学习者难点、伙伴讲解、关键问答、突破时刻、讨论主题
- **铁律**: 必须基于真实对话，绝不虚构未发生的内容
- **稀疏对话处理**: 如果学习者几乎没说话，只写一句陈述（如"学习者只回了'灵霓'就下课，本节课没进入教学内容"）
- **合并**: 服务器自动将新条目合并到现有 pal_moments.md 前面

### ===PROGRESS_MD===
- **内容**: 当前教材的学习进度
- **核心字段**: 
  - `当前页码：N` — 逻辑页码
  - 本节课完成了哪些内容
  - 学习者的理解和掌握情况
  - 下次课建议从哪里继续
- **铁律**: 基于真实对话，不能编造进度

### ===DIARY_ENTRY===
- **格式**: `## YYYY-MM-DD` + 正文
- **日期**: 必须使用真实当前日期，不能使用故事设定中的虚构日期
- **视角**: 第一人称（学习者视角）
- **即使没说话**: 也要写一两句，带上教材名 + 伙伴名
- **存储**: 追加到 `diary/YYYY-MM.md`

### ===RELATION_MD===
- **内容**: 伙伴与学习者关系的变化
- **格式**: 自由文本，建议简洁
- **限制**: ≤ 150 tokens
- **特殊**: 如果关系无变化，可留空

### ===COMPANION_NOTE===
- **内容**: 伙伴的内心独白（不展示给学习者）
- **限制**: ≤ 80 字符（按语言自适应）
- **格式**: 去除旁白星号后的纯文本
- **语言**: 遵守授课语言要求

**最容易漏的一段——特别注意写完整。**

### ===END===
- **纯标记**: 无内容，表示输出结束

## 解析容错

服务器解析逻辑（函数 `D()`）:
- 按 `===TAG===` 正则匹配分割
- 对 COMPANION_NOTE 做后处理：去除单星号旁白格式、压缩多余空格、按最大长度裁剪（从句末边界截断）
- 如果 FAREWELL / PAL_MOMENTS_MD / PROGRESS_MD / COMPANION_NOTE 任一为空 → 解析失败
- 解析失败 → 重试一次（使用相同参数再次调用 LLM）
- 重试也失败 → 返回错误给前端

---

## 空课保护

开课时即检查学习者是否在首条消息就点击了下课：

- **0 条实质发言**: 所有段按"空课"模式处理
  - PAL_MOMENTS: 一句事实陈述
  - COMPANION_NOTE: 极简招呼
  - DIARY_ENTRY: 一两句，仍带教材名 + 伙伴名
  - PROGRESS_MD: 仅记录伙伴讲了什么（可能是"未进入教学"）
  - RELATION_MD: 留空

---

## 对 MVP 的启发

MVP 不需要 7 段这么复杂。建议简化为 3 段：

1. **告别语** — 直接展示
2. **进度记录** — 存储到本地
3. **学习总结** — 存储到本地

分隔符格式可以保留（`===TAG===`），因为它给 LLM 一个明确的输出结构协议，解析也简单。
