## Overview

直接构建 Electron + React + Tailwind 桌面应用，实现单用户、本地优先、DeepSeek 驱动的 Socratopia-like 核心学习闭环。跳过单页网页原型，不做社区、商城、订阅、多用户。

## Architecture Decisions

- DeepSeek-only：减少 provider 抽象复杂度，优先验证学习体验。
- Electron from start：用户明确要求直接第二层，并且需要本地文件系统和安全 Key 存储。
- Local-first storage：从第一版开始使用 appData 文件系统，避免后续从 localStorage 迁移。
- Single-user：不做登录、权限、多租户、云同步。
- Reuse all characters：9 个角色 Markdown 从 `reference/角色设定/candidates/` 进入本地候选角色池。

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| Electron 安全边界配置错误 | High | Task 2 单独验证；禁止 renderer 访问 Node |
| DeepSeek streaming IPC 复杂 | Medium | 先 mock stream，再接真实 API |
| Prompt 输出变成讲答案 | High | Prompt builder snapshot + 手动课堂 QA |
| 文件布局过度复杂 | Medium | 第一版保留层级但简化 message 存储 |
| 下课产物解析失败 | Medium | 保存 raw 输出，允许重试 |
| 角色内容公开复用存在 IP 风险 | Low for personal use | 当前仅个人自用；未来公开发布需重写角色 |
