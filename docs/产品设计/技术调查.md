## 3. 对 Socratopia-Local 的影响

v3.x 的新增系统说明 Socratopia 已从“9 角色 + 教材课堂”扩展为“世界构建 + 社区分享 + 角色创作 + 费曼宠物 + 手册/工坊”的平台化产品。但本项目的用户约束是个人自用、本地优先，因此不追随平台化路线。

当前应吸收的部分：

- 世界系统的本地结构思想。
- 伙伴槽位和角色模板概念。
- 课堂快捷键和本地工具体验。
- 课后产物和学习记录。
- 女娲/萌宠作为后续灵感，而不是第二层范围。

当前明确不做的部分：

- Agora 社区、发布、分享、愿望单、工坊。
- 书币、商城、订阅、支付。
- 多用户账号、论坛身份、云同步。
- 完整女娲世界构建 AI。
- 萌宠费曼教学系统。

## 4. DeepSeek API 调查

来源：
- https://api-docs.deepseek.com
- https://api-docs.deepseek.com/api/create-chat-completion
- https://api-docs.deepseek.com/quick_start/pricing
- https://api-docs.deepseek.com/quick_start/error_codes
- https://api-docs.deepseek.com/quick_start/rate_limit
- https://api-docs.deepseek.com/guides/thinking_mode
- https://api-docs.deepseek.com/guides/kv_cache

### 4.1 API 形态

DeepSeek 提供 OpenAI-compatible API：

- Base URL：`https://api.deepseek.com`
- Chat Completions：`POST /chat/completions`
- Auth：`Authorization: Bearer ${DEEPSEEK_API_KEY}`
- 支持标准 SSE streaming，`data: [DONE]` 结束。

### 4.2 模型选择

当前 V4 模型：

| 模型 | 用途 |
|---|---|
| `deepseek-v4-pro` | 默认课堂模型，适合推理、代码、复杂对话 |
| `deepseek-v4-flash` | 经济快速模型，适合摘要、闪卡、轻量任务 |

旧别名 `deepseek-chat` / `deepseek-reasoner` 已标记为将退役，不应作为新项目默认模型。

### 4.3 Streaming 约束

SSE 流中可能包含：

- `data: {...}` JSON chunk
- `data: [DONE]`
- `: keep-alive` 注释行
- 空行

主进程负责解析 DeepSeek SSE 或 SDK stream，并通过 IPC 将纯 JSON chunk 发送给 renderer。

### 4.4 Thinking mode

DeepSeek 支持：

```json
{"thinking": {"type": "enabled"}}
```

建议：

- 课堂追问默认使用 `deepseek-v4-pro` + thinking enabled。
- 摘要/闪卡可使用 `deepseek-v4-flash` 或关闭 thinking 以降低成本。
- 不把 `reasoning_content` 原样展示给用户，除非后续明确设计“思考过程”视图。

### 4.5 错误处理

| HTTP | 含义 | 应用行为 |
|---|---|---|
| 400 | 请求体无效 | 记录开发错误，提示请求格式问题 |
| 401 | API Key 无效 | 提示重新设置 Key |
| 402 | 余额不足 | 提示 DeepSeek 余额不足 |
| 422 | 参数无效 | 阻止请求并记录参数 |
| 429 | 并发/速率限制 | 指数退避，允许用户重试 |
| 500 | 服务端错误 | 自动短重试，仍失败则提示 |
| 503 | 服务过载 | 延迟重试 |

## 5. Electron 安全边界

来源：https://www.electronjs.org/docs/latest/tutorial/security

本项目虽然只服务个人，但 API Key 仍然代表真实费用账户，必须避免出现在 renderer。

要求：

- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`
- preload 只通过 `contextBridge.exposeInMainWorld` 暴露最小 API。
- 禁止暴露原始 `ipcRenderer`、`fs`、`shell`。
- 所有 IPC 入参使用 Zod 校验。
- DeepSeek API 调用只在 main process 中发生。
- API Key 使用 Electron `safeStorage` 或 OS keychain 加密保存。

推荐边界：

```text
Renderer (React)
  -> window.socratopia.chat.stream(...)
Preload
  -> ipcRenderer.invoke / on typed channels
Main Process
  -> validate with Zod
  -> read API key from safe storage
  -> call DeepSeek
  -> stream chunks back
Local Data Layer
  -> write conversations/progress/diary/textbooks
```

## 6. 当前实现结论

第二层应直接以桌面应用架构开始，但范围仍应保持个人工具最小闭环：Electron 安全壳、DeepSeek 主进程客户端、本地文件数据层、9 个角色 + world preset 加载、Prompt 组装器、单用户课堂聊天 UI、课后 summary / flashcards / diary / progress。

v3.2.0 的 Agora、女娲、萌宠、商城、社区、愿望单、工坊不进入第二层。
