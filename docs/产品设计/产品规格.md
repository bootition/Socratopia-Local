# 产品规格：Socratopia-Local 第二层

日期：2026-07-06

## 1. 一句话定义

Socratopia-Local 是一个单用户、本地优先的桌面 AI 学习伴侣。用户导入自己的教材，选择本地角色，角色通过苏格拉底式追问陪用户学习，并把对话、进度、总结、闪卡和日记保存到本地文件系统。

## 2. 范围边界

### 2.1 必做

- Electron 桌面应用。
- React + Tailwind 课堂 UI。
- DeepSeek API Key 设置与安全存储。
- DeepSeek 流式聊天。
- 复用全部 9 个角色 Markdown。
- 复用 `world_preset.md`。
- 本地文件系统持久化。
- Markdown / KaTeX / 代码高亮渲染。
- 教材导入：第二层至少支持 Markdown 和纯文本；PDF/EPUB 可作为后续任务，但数据模型必须预留。
- 对话历史保存。
- 基础搜索。
- 课后 summary / flashcards / diary / progress。

### 2.2 不做

- Socratopia 账号、订阅、支付、书币、商城。
- Agora 社区、论坛、分享、愿望单、工坊。
- 云同步、多设备同步、多租户。
- 完整女娲世界构建 AI。
- 萌宠费曼教学系统。
- 生产级自动更新。
- 多 LLM provider 抽象；当前只做 DeepSeek。

## 3. 用户画像

唯一用户：本机个人使用者。

隐含要求：不需要注册登录、不需要权限系统、不需要服务端数据库、数据可被手工备份/复制/迁移、API Key 必须避免泄露到 renderer。

## 4. 核心用户流程

### 4.1 首次启动

1. 用户打开应用。
2. 应用检测本地数据目录是否存在。
3. 如果无 DeepSeek API Key，显示设置界面。
4. 用户输入 API Key。
5. main process 使用 `safeStorage` 加密保存。
6. 初始化 default profile、default world、9 个候选角色索引。

验收标准：API Key 不写入 renderer storage；重启后可检测 Key 是否已配置；本地数据目录结构自动生成。

### 4.2 创建/进入课堂

1. 用户选择角色。
2. 用户选择教材或粘贴本节学习材料。
3. 应用创建 conversation。
4. Prompt 组装器注入角色、世界观、教材片段、学习进度、旁白规则、语言规则。
5. 用户发消息。
6. DeepSeek 流式返回。
7. UI 实时显示角色回复。
8. 每条消息保存到本地。

验收标准：角色回复包含角色语气与旁白；角色不能直接变成普通答题机器；回复应尽量以追问结束；断网或 DeepSeek 错误时不会丢失用户消息。

### 4.3 教材导入

第二层第一版最低支持 `.md`、`.txt`、手动粘贴文本。PDF/EPUB 后续加入，但目录结构预留：

```text
textbooks/{textbookId}/
  metadata.json
  source.md
  progress.md
  current_reading.md
  pages.json
  toc.json
```

验收标准：导入后可在课堂选择；教材内容可注入 Prompt；progress 可以记录当前位置。

### 4.4 下课与学习产物

用户点击“下课”按钮触发，不允许 AI 主动下课。

下课后生成：

- `lesson_summaries/{convId}.md`
- `flashcards/{convId}.json`
- `diary/YYYY-MM.md`
- `textbooks/{textbookId}/progress.md`
- `handoff_tail.json`

验收标准：下课产物由 DeepSeek 生成并经本地解析保存；失败时保留原始返回，允许重新生成；下次课堂可注入 handoff tail。

## 5. 本地数据模型

建议数据根目录：

```text
{appData}/Socratopia-Local/
  config/
    settings.json
    deepseek-key.enc
  profiles/
    default/
      active_world.json
      worlds/
        default/
          story.md
          learner_profile.md
          pal_moments.md
          npc_a.md
          npc_b.md
          npc_c.md
          companions_index.json
          textbooks/
          conversations/
          diary/
          lesson_summaries/
          flashcards/
          search_index.json
  custom_companions/
    index.json
```

说明：虽然是单用户，仍保留 `profiles/default`，避免未来迁移困难。第一个 world 命名为 `default`。9 个候选角色保留在项目 `reference/` 中，初始化时复制或索引到 appData。对话第一版可用单个 `messages.jsonl`，后续再拆分。

## 6. 模块边界

### Main process

- `deepseekClient`：DeepSeek SDK / streaming。
- `secureKeyStore`：API Key 加密保存和读取。
- `localStore`：文件系统 CRUD。
- `promptBuilder`：组装 system prompt。
- `lessonArtifacts`：下课产物生成与解析。
- `ipcHandlers`：Zod 校验后的 IPC 边界。

### Preload

只暴露 `window.socratopia`，包含 settings、companions、textbooks、conversations、chat、artifacts 等命名空间。禁止暴露 `ipcRenderer`、`fs`、DeepSeek API Key。

### Renderer

设置页、角色列表、教材列表、课堂聊天、历史记录、课后产物视图。

## 7. Prompt 规则

第二层 Prompt 至少包含：简化苏格拉底教学规则、当前角色 Markdown、世界观 `world_preset.md`、学习者信息、当前教材片段、近期对话摘要或 handoff tail、旁白与格式规则、授课语言：中文。

必须遵守：不直接长篇灌输答案；优先追问和引导；每条回复包含简短第三人称旁白；正文尽量短；结尾尽量是问题；下课只能由用户点击按钮触发。

## 8. 成功标准

第二层完成时必须满足：应用可启动为桌面 App；用户可设置 DeepSeek API Key；用户可选择 9 个角色之一开始课堂；用户可导入/粘贴教材内容；用户可进行流式苏格拉底式对话；所有对话和学习产物保存到本地文件系统；重启应用后历史仍在；API Key 不出现在 renderer 或普通明文配置中；至少有一个完整闭环：上课 → 对话 → 下课 → 生成 summary/flashcards/diary/progress → 下次注入 handoff。
