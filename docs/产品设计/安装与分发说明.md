# 安装与分发说明（Socratopia-Local）

日期：2026-09-15 · 版本：0.1.0

## 一、四种分发形态（都在 `release/` 下）

| 文件 | 用途 | 是否需要管理员 |
|---|---|---|
| `Socratopia-Local-Setup-User-0.1.0.exe` | **当前用户安装器**（推荐）：只装给自己，写入用户目录 | 否 |
| `Socratopia-Local-Setup-Machine-0.1.0.exe` | **全机安装器**：装给这台电脑的所有用户，需要 UAC | 是 |
| `Socratopia-Local-Portable-0.1.0.exe` | **便携版**：双击即用，不写安装目录、不创建快捷方式 | 否 |
| `Socratopia-Local-0.1.0-win-x64.zip` | **便携压缩包**：解压后运行 `Socratopia-Local.exe` | 否 |

> 用户级安装器的向导里也可以临时选择「为使用这台电脑的任何人安装」；两个安装器除了默认安装模式和默认目录外没有差别。

## 二、用户级安装流程

1. 双击 `Socratopia-Local-Setup-User-0.1.0.exe`。
2. 选择「**仅为我安装**」→ 下一步。
3. 安装位置页：
   - 默认是 `%LOCALAPPDATA%\Programs\Socratopia-Local`；
   - 安装器会**先试写**该目录：不可写时自动回退到 `%LOCALAPPDATA%\Socratopia-Local` → `%USERPROFILE%\Socratopia-Local` → `%USERPROFILE%\Documents\Socratopia-Local`，并用弹窗告知新路径；
   - 如果所有默认位置都不可写，会**明确提示**「无法写入安装目录」，停在当前页，让你手动选一个可写目录（例如 `D:\Socratopia-Local`）或用便携版——不会再出现装到一半失败、写卸载程序失败的情况。
4. 点「安装」→ 完成。桌面与开始菜单会创建 `Socratopia-Local` 快捷方式。
5. 首次启动：粘贴 DeepSeek API Key → 先点「测试连接（不保存）」→ 保存进入课堂。

## 三、卸载与数据

- 通过「设置 → 应用 → Socratopia-Local → 卸载」，或安装目录里的 `Uninstall Socratopia-Local.exe`。
- **卸载不会删除学习数据**。数据保留在：
  `%APPDATA%\Socratopia-Local\Socratopia-Local`
  需要彻底删除时手动删除该目录即可（卸载时会再次提示这一点）。

## 四、常见问题

**1. 安装时提示「无法写入安装目录」**
说明默认目录不可写（常见于受管控的 Windows 配置）。点「上一步」回到安装位置页，把路径改成可写目录，例如 `D:\Socratopia-Local`；或者直接使用便携版。

**2. 安装时提示「Socratopia-Local 无法关闭，请手动关闭它后重试」**
安装器检测到应用正在运行（文件被占用）。关闭所有 Socratopia-Local 窗口（任务管理器里结束残留进程）后点「重试」。

**3. Windows 提示「未知发布者 / SmartScreen 已阻止」**
当前安装包**未做代码签名**（本地自用版本）。点「更多信息」→「仍要运行」即可；介意的用户可使用便携版（同样会提示一次）。

**4. 便携版和安装版的数据互通吗？**
互通。两者都使用同一个用户数据目录 `%APPDATA%\Socratopia-Local\Socratopia-Local`，也都可以在「设置」里导出/恢复备份。

**5. 升级**
直接运行新版本的安装器覆盖安装即可；用户数据不受影响。安装前先退出正在运行的应用。

## 五、开发者：重新构建

```bash
npm install
npm test            # typecheck + 全部单测 + 安全基线
npm run dist        # 三条分发路径：User 安装器 + Machine 安装器 + Portable + zip
npm run dist:user   # 只构建当前用户安装器
npm run dist:machine# 只构建全机安装器
```

- 安装器自定义逻辑在 `build/installer.nsh`（目录可写性预检 / 自动回退 / 卸载保留数据提示）。
- 构建脚本：`scripts/dist.mjs`。
- 提交/推送请使用 `npm run ship`（门禁通过后自动提交、推送并核对远端 ref，见 `AGENTS.md`）。
