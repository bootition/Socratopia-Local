# Socratopia-Local 0.1.0 发布说明

发布日期：2026-09-15 · 平台：Windows x64

## 这是什么

本地优先的 AI 苏格拉底式学习伴侣：Electron 桌面应用，直连你自带的 DeepSeek API Key，
不上传教材与对话到任何第三方服务（除 DeepSeek API 本身），不做账号/云同步/社区。

## 本版亮点

- **角色化课堂**：9 个内置角色 + 自定义角色（创建/编辑/删除，索引丢失可从 markdown 恢复）
- **多格式教材**：Markdown / 纯文本 / PDF（逐页提取）/ EPUB / Word (.docx)，保留原始文件，课堂可按页阅读与引用
- **学习闭环**：流式课堂、笔记与四色高亮、划词工具条、消息编辑；下课后生成总结/闪卡/日记/进度/接力产物，失败项可单独重试
- **进度与统计**：教材进度条、完成课堂、token 用量与费用估算
- **可靠性**：本地 JSON/JSONL 原子写、并发串行化、索引损坏自动恢复；两轮红队审查修复 40+ 项问题
- **接入友好**：首次启动「测试连接」验证 Key/网络/模型；错误提示中文化（Key 无效/余额不足/限流/超时/网络）
- **分发完整**：当前用户安装器、全机安装器、便携版、便携 zip；安装前检测目录可写性，不可写时自动回退或明确报错

## 安装 / 升级 / 卸载

- 安装：双击对应安装器 → 选择安装位置 → 完成；桌面与开始菜单会创建快捷方式。
- 升级：退出正在运行的应用，直接运行新版安装器覆盖安装；学习数据不受影响。
- 卸载：控制面板或安装目录的卸载程序；**学习数据保留**在
  `%APPDATA%\Socratopia-Local\Socratopia-Local`，需要时可在「设置 → 恢复备份」中使用。
- 安装包未做代码签名，Windows 可能提示「未知发布者」：点「更多信息 → 仍要运行」即可。
- 详细说明与故障排查：[安装与分发说明](安装与分发说明.md)。

## 首次使用

1. 粘贴 DeepSeek API Key → 点「测试连接（不保存）」确认可用 → 保存进入课堂。
2. Companion 选择角色（可新建自定义角色）。
3. Textbook 导入教材（Markdown/文本/PDF/EPUB/Word）。
4. Classroom 提问；点「下课」生成产物；在 History / Notes / Stats / Progress 回看。

## 已知限制

- 不支持 OCR（扫描版 PDF）、语音、云同步、书城/社区（与既定范围一致）
- 安装包未签名；首次运行会有一次 SmartScreen 提示
- Word 导入有 100MB 输入与 200MB 声明解压总量上限
- 目前仅构建 Windows x64；macOS/Linux 目标保留在配置中但未验证
